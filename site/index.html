Home run and strikeout probabilities, scored from real Statcast batted-ball data, pitcher matchups, park, and weather.
Built from Baseball Savant Statcast leaderboards (season) and raw Statcast pitch-level data (rolling 21-day recent form), MLB Stats API schedule/lineups/probable-pitchers/weather, and a static HR park-factor table. Ali Score is a weighted composite (Baseline power/stuff profile × 0.6–0.65, Opportunity matchup/park/weather/lineup context × 0.35–0.4) scored relative to today's slate. HR, hit, total-base, and strikeout probabilities are model-projected from each player's own real per-plate-appearance rates adjusted for the matchup — not sportsbook odds, and not calibrated against actual game outcomes the way a trained model would be. Parlay combined probabilities assume independence between legs; same-game legs are usually correlated in reality. No Vegas lines or market odds are connected. Confirmed lineups usually post a few hours before first pitch — until then, a team's most recent actual batting order is shown and flagged "Projected Lineup." Pitcher-vs-batter handedness splits and per-pitch-type matchup simulation are not modeled (simplified vs. the proprietary methodology this was inspired by); pitcher matchup uses each starter's overall Statcast vulnerability instead. Refreshed once daily; the last 7 days are kept and browsable via the date picker above, then age out automatically.
